## 📖 О проекте

**Гофроагрегат** — обучающее приложение-симулятор для операторов гофроагрегатов.
Моделирует реальную линию **Fosber** для производства пятислойного гофрокартона.

Игрок выбирает свою **роль** на линии, устраняет **брак** и **поломки**,
отвечает на вопросы **знатока** и проходит **викторины** по своему участку.

## 🎮 Роли

| Роль | Разряд | Участок | Описание |
|------|--------|---------|----------|
| **Модульщик** | 5 | Модуль | Р4, Р5, двухслойка. Занят сырьём и гофрой. |
| **Лицевик** | 4 | Склейка | Лицевой слой, склейка, натяжение. |
| **Релёвщик** | 4 | Релёвки | Релёвки, биговки, обрезь. |
| **Хвостовик** | 4 | Хвост | Выход картона, укладчик, палеты. |
| **Бригадир** | 6 | Пульт | Натяжение, температура, клей, заказы. |

## ✨ Что умеет приложение

### 🎯 Игровой процесс
- 🎭 **Выбор роли** — 5 ролей с разными участками и обязанностями
- 📋 **Заказы** — трёхслойка и пятислойка с параметрами (ширина, обрезь, резка, длина)
- 📦 **Палеты** — автоматический подсчёт стоп и отправка на склад
- 👥 **Смена бригад** — каждые 50 действий меняется бригада и карщик

### ⚠️ Проблемы и брак
- 🔴 **4 участка** с уникальным браком: Модуль, Склейка, Релёвки, Хвост
- 📚 **17 видов брака**: разрыв гофров, расклей, флютинг, коробление, кинзу и др.
- 🔧 **12 видов поломок**: заклинивание, износ шабера, засор валика и др.
- ⏱️ **Автоустранение** — если не успел, брак уходит в отходы

### 🧠 Обучение
- 📝 **Викторина по проблеме** — сразу после брака
- 🎓 **Вопросы по участку** — общие знания по роли
- 🧙 **Знаток смены** — Николаич/Петрович/Михалыч комментирует, даёт подсказки
- 📖 **20 вопросов** к знатоку с ответами по технологии
- 📜 **12 историй** из опыта знатока

### 🖥️ Интерфейс
- 🎨 **Анимированная схема агрегата** — с вращением валов, движением бумаги, паром
- 🖱️ **Тап по узлу** — справка по каждому узлу (Р1-Р5, М1, М2, мосты, ножи и т.д.)
- 📊 **Индикаторы** — уровень клея, износ агрегата
- 🎛️ **Пульт бригадира** — 8 слайдеров (натяжение, температура, клей, пар)
- 💬 **Лог событий** — цветные сообщения с описанием
- 📧 **Кнопка репорта** — отправка замечаний на email автора

## 🚀 Установка APK

### Способ 1: Готовый APK (рекомендуется)

1. Перейдите в раздел [**Actions**](../../actions) репозитория
2. Выберите последний успешный workflow (зелёная галочка ✅)
3. Скачайте артефакт **gofroagregat-apk**
4. Распакуйте ZIP-архив → внутри файл `gofroagregat-1.0.0-debug.apk`
5. Перекиньте APK на телефон и установите

### Способ 2: Локальная сборка

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Ostenvrn/gofroagregat.git
cd gofroagregat

# 2. Установите зависимости (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install -y \
    git zip unzip openjdk-17-jdk \
    autoconf libtool pkg-config \
    zlib1g-dev libncurses5-dev libncursesw5-dev libtinfo5 \
    cmake libffi-dev libssl-dev

# 3. Создайте виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# 4. Установите Buildozer и Cython
pip install --upgrade pip
pip install buildozer cython

# 5. Соберите APK
export P4A_IGNORE_RECIPES=libthorvg
buildozer android debug

# APK появится в папке: bin/gofroagregat-1.0.0-debug.apk


Как играть

    Запустите приложение — появится выбор роли

    Выберите роль — от неё зависят участок и тип брака

    Нажмите СТАРТ — начнётся смена

    Следите за логом — там появляются события, брак и поломки

    Устраняйте проблемы — время ограничено (6 секунд на брак, 12 на поломку)

    Отвечайте на викторины — кнопка ТЕСТ

    Тап по схеме — справка по любому узлу

    Спросите знатока — кнопка СПРОСИТЬ ЗНАТОКА (20 вопросов по технологии)
