# Обучающий симулятор гофроагрегата

Симулятор работы на гофроагрегате Fosber. Моделирует работу линии, позволяет отрабатывать нештатные ситуации без риска для оборудования.

## Стек
- Python, Kivy
- GitHub Actions (настройка CI/CD в процессе)

## Как запустить
1. Установите Kivy
2. Запустите: python main.py

## Планы
- Переход на Flet
- Сборка APK
- Добавление подробной схемы агрегата
